# VodRecovery-Twitch1Button


This is a fork for https://github.com/MacielG1/VodRecovery

How to install:

Download the repository from GitHub (Click green Code button Download ZIP), and extract the zip file somewhere permanent on your PC.

Make sure you have Python installed and checked "Add Python to PATH" during Python installation.

Double-click setup.bat (Click "Yes" when Windows asks for permission). This installs all required libraries and configures your computer to recognize the Twitch button.

Open your chromium-based browser and to the extensions page 

Turn on Developer mode 

Click Load unpacked 

Select the "extension" folder.

Go to any live Twitch stream and click on your new VodRec button next to the Subsrcibe button.
